# Boyfriend Mode

A GTA-style browser game for him, made by her. She opens the site, enters both names, picks or writes missions, and sends him the generated link (`?g=...`). He plays through her missions (boba runs, flowers, holding bags, outfit quiz, golden-hour pic on the yacht) while a "Girlfriend Rage" meter fills when he is late or answers wrong.

- Stack: Vite + Three.js, single-player, static site (Vercel).
- Dev: `npm install && npm run dev`
- Build: `npm run build` → `dist/`
